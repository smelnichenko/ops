# Free online address data sources, EU-27 - research behind the report

Question: for every EU member state, which address data sources (house-number level, ideally with
coordinates and postcodes) are available online for free? Feeds masi plan 114 (places per market
country, one `PlacesFeed` per country).

**State, 2026-11-11 18:18 (Europe/Tallinn): complete. Research and the independent check are done
for all 27 countries and the EU-wide layer (1,205 claims: 966 confirmed, 78 corrected, 10 wrong,
126 unverified, 17 negative claims not disproved, 8 other). The report is
[../../eu-free-address-data-sources.md](../../eu-free-address-data-sources.md).
[by-country/README.md](by-country/README.md) shows the verdict counts per country.**

## How to read a verdict

- CONFIRMED: the checker requested the source itself on 2026-11-11 and saw it.
- CORRECTED / WRONG: the notes were off; the right value is in the check table and in the list at
  the top of the region's verification file. The research notes themselves are left as written.
- UNVERIFIED: could not be checked (site refused the client, login needed, file too large to
  recount, certificate invalid). Nothing was bypassed: no spoofed headers, no TLS override.
- NOT DISPROVED: a negative claim ("no open register exists") that a search of the national portal
  and the EU catalogue failed to disprove. Not proof of absence.

## Known gaps

- No per-country INSPIRE Addresses overview: the INSPIRE Geoportal's TLS certificate has been
  expired since 2026-10-30 and was not bypassed.
- No official per-country compliance table for addresses under Regulation 2023/138 was found.
- Large files were not recounted, so national record counts mostly rest on the researcher's count
  or the publisher's figure.
- The research missed Eurostat's GISCO Address API as a per-country source (keyless; found serving
  HU, PT, MT, ES, IT by the checkers). The report must state it for every country it covers.

## To change the report

Edit the country's file in `report/` (or `notes/` and rerun `split_by_country.py` if the evidence
changed), then run `python3 -I build_report.py`. A copy of the report is also kept, untracked, at
`/home/sm/src/monitor/reports/EU free address data sources.md`.
