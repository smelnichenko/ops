4. s.4, Photon planet database for 1.x: now 63.2 GB, updated 2026-11-10 09:56 (notes: 63.1 GB, 2026-11-03 - superseded by a newer build).
5. s.5, Overture gap "Azure paths not found": the addresses guide lists `https://overturemapswestus2.blob.core.windows.net/release/2026-10-21.0/theme=addresses/type=address/*`.
6. s.5, Overture gap "data vintage per country not stated": the attribution page gives "Accessed: 2026-10-15" for every EU source (the pull date, not the register's reference date).
7. s.5, inference that Overture inherits OpenAddresses' vintage "source by source": Overture labels 15 of the 19 EU countries "Distributed by OpenAddresses", but not Belgium, Czechia, the Netherlands and Slovenia. Slovenia has had no successful OpenAddresses address run since 2024-06-14, yet Overture lists 580,213 Slovenian addresses accessed 2026-10-15.
