# Free online address data sources in Spain, Portugal, Italy and Malta (state as of 11 November 2026)

Method note: every "verified" item below was opened or downloaded directly on 2026-11-11 (HTTP status, file headers, and where stated the file contents). Items taken only from a search-engine summary or a third-party description are marked "unverified" or "secondary". Counts labelled "own count" were computed from the downloaded official file, not quoted from a publisher.

## Spain: which free address data sources exist, and on what terms?

### Takeaway
Spain has open, free, house-number-level address data with coordinates and postcodes for the whole country: CartoCiudad (IGN/CNIG, CC BY 4.0, ~15.7 million address points, rebuilt every four months) is the national aggregate and is the dataset declared as the "Addresses" High-Value Dataset; the Catastro INSPIRE Addresses ATOM feed is the main underlying source (free, no registration, updated twice a year, but excludes the Basque Country and Navarra, which publish their own data). The one practical obstacle is that the CNIG download centre gates file downloads behind reCAPTCHA, so unattended bulk download is easier through the OGC API Features service or the Catastro ATOM feed.

### Cited Findings

**National aggregate: CartoCiudad (IGN / CNIG, Sistema Cartográfico Nacional)**
- CartoCiudad ("Direcciones postales de CartoCiudad") is published by the Centro Nacional de Información Geográfica (CNIG) for the Instituto Geográfico Nacional; the download product is a spatial dataset per province in GeoPackage format with the layers `portalpk_publi` (address points: portales and kilometre points) and `manzana` (urban blocks) — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad)
- Download unit is the province (52 files; examples: A Coruña 51.24 MB, Barcelona 141.81 MB, Araba/Álava 2.84 MB, Ceuta 1.04 MB); CRS is ETRS89 geographic longitude/latitude for the peninsula, Balearics, Ceuta and Melilla, and REGCAN95 for the Canary Islands; road geometries are not included (they are in the separate "Redes de Transporte" product) — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad)
- Attributes of `portalpk_publi` (specification v15, PDF dated 2025-12-18): `id`, `id_porpk`, `tipo` (Portal or PK), `tipo_vial`, `nombre_via`, `numero`, `extension`, `id_pob`, `poblacion`, `cod_postal` (mandatory), `ine_mun`, `municipio`, `provincia`, `comunidad_autonoma`, `fuente_datos`, `fecha_modificacion`; geometry is a point — [CartoCiudad documentation ZIP (contains CartoCiudad_Especificaciones_v15.pdf), verified download 2026-11-11](https://centrodedescargas.cnig.es/CentroDescargas/documentos/Cartociudad_documentacion.zip)
- Update frequency for postal addresses is "cuatrimestral" (every four months); in each cycle the dataset is regenerated completely and replaces the previous version — [CartoCiudad documentation ZIP, specification v15 section 8](https://centrodedescargas.cnig.es/CentroDescargas/documentos/Cartociudad_documentacion.zip); same frequency stated in [CNIG "Fuentes oficiales – Direcciones postales", May 2026](https://www.idee.es/resources/documentos/Cartociudad/Fuentes_direcciones.pdf)
- Release log: latest release 10-11-2026 (portals and kilometre points updated from national, regional and local sources); earlier releases 11-05-2026, 02-03-2026, 20-11-2025 (new attribute giving the data source of each address), 13-06-2025 (new attributes for update date and municipality/province/region), 10-06-2024 (data now provided in GeoPackage format; addresses linked to latest Correos postcodes), 15-12-2023 — [CNIG novedades, CartoCiudad series](https://centrodedescargas.cnig.es/CentroDescargas/novedades?codSerie=02122)
- Licence: access unrestricted, use "Datos sujetos a licencia CC BY 4.0" per the specification; the download page refers to Orden FOM/2807/2015 and an IGN licence described as compatible with CC BY 4.0; attribution is required — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad); [Orden FOM/2807/2015](https://www.boe.es/boe/dias/2015/12/26/pdfs/BOE-A-2015-14129.pdf); [IGN licence conditions](http://www.ign.es/resources/licencia/Condiciones_licenciaUso_IGN.pdf)
- Commercial reuse: CNIG states that all users can use, reuse and redistribute the information "sin discriminación alguna ni restricciones de uso comercial" — [CNIG paper, JIIDE 2024](https://www.idee.es/resources/documentos/Cartociudad/JIIDE/2024_publicacion_datos_geoespaciales_alto_valor_cartociudad.pdf)
- Suggested attribution string used by reusers: "CC BY 4.0 www.scne.es/productos.html#CartoCiudad" — [datos.gob.es, Callejero Digital de Andalucía Unificado record](https://datos.gob.es/en/catalogo/e0dat0002-callejero-digital-de-andalucia-unificado); OpenAddresses records the licence as CC BY 4.0 with attribution name "scne.es" — [OpenAddresses sources/es/countrywide.json](https://github.com/openaddresses/openaddresses/blob/master/sources/es/countrywide.json)
- Registration and automation (verified in the page source 2026-11-11): the download page shows an optional "Iniciar sesión" link, and each direct download first calls `preAutorizarDescarga` with a Google reCAPTCHA v3 token and runs a check for automated browsers (`navigator.webdriver`) before the file is served. I did not attempt to pass this gate — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad)
- Sources integrated by CartoCiudad (May 2026 list): IGN transport network (IGR-RT), Dirección General del Catastro, Gobierno Vasco, CDAU (Andalucía), IDE Catalunya (INSPIRE addresses), Gobierno de La Rioja, Gobierno de Navarra, Institut Cartogràfic Valencià, Comunidad de Madrid, Govern Illes Balears, and the municipalities of Cáceres, Albacete, Santander, València, Caravia, Gijón, Santa Cruz de Tenerife, Soto del Barco, Sariego, Gozón, Oviedo, Avilés, Pravia and Navia — [CNIG "Fuentes oficiales – Direcciones postales", May 2026](https://www.idee.es/resources/documentos/Cartociudad/Fuentes_direcciones.pdf)
- Position of Catastro-sourced points: "Cuando es posible, el portal se sitúa en la entrada del edificio y en otros casos el centroide de la parcela catastral" — [CNIG "Fuentes oficiales – Direcciones postales", May 2026](https://www.idee.es/resources/documentos/Cartociudad/Fuentes_direcciones.pdf)

### Inferences
- Spain has no single statutory national address register; CartoCiudad is an aggregate rebuilt from cadastral, statistical, regional and municipal sources, so it is the best single free source but inherits the quality and vintage of each contributor (the `fuente_datos` and `fecha_modificacion` attributes make this traceable).
- For unattended bulk acquisition the realistic routes are (a) paging the OGC API Features `address` collection (about 1,570 requests at 10,000 features each) or (b) the Catastro ATOM feed (thousands of small per-municipality ZIPs, plus Navarra and Basque sources separately); the CNIG GeoPackages need a browser because of reCAPTCHA.
- The gap between "19 million" addresses in the geocoder (June 2024) and 15.66 million in the API collection (November 2026) probably reflects different content scopes or de-duplication, not a loss of coverage; this is not confirmed by any source.
- The Catastro licence position is ambiguous: current metadata says CC BY 4.0 while the linked 2016 licence PDF restricts redistribution of untransformed data. Reusers who redistribute raw Catastro files should rely on the CartoCiudad CC BY 4.0 release or seek confirmation.
- The Navarra CSV coordinates look like ETRS89 / UTM zone 30N metres despite the `lon`/`lat` column names (inferred from value ranges only).

### Gaps
- Exact record count and total size of the 52 CartoCiudad GeoPackages: not measured because downloads are behind reCAPTCHA.
- Rate limits or fair-use terms for the CartoCiudad geocoder and API Features: none found on the pages opened.
- A direct bulk download URL for the Basque Country street directory (geoEuskadi FTP) was not found; licence appears as CC BY 3.0 in one catalogue and CC BY 4.0 (NORA) in a secondary source.
- Whether Catastro has formally replaced its 2016 licence text with CC BY 4.0: unresolved.
- Correos' own postcode products and prices were not checked; no open Correos download was found.

## Portugal: which free address data sources exist, and on what terms?

### Takeaway
Portugal does have an open national address-point dataset: INE's "Base Nacional de Moradas" (National Address Base), an INSPIRE Addresses dataset for all 308 municipalities with coordinates, door numbers, unit designators and postcodes, under CC BY 4.0, downloadable without registration. Its weakness is age: the files on the server date from January–April 2018 (version 2017) even though the metadata calls the update frequency "continuous". The CTT postcode file needs a free account and has no coordinates; current door-number data exists only for a few municipalities.

### Cited Findings

**National dataset: Base Nacional de Moradas (BNM), Instituto Nacional de Estatística (INE)**
- INE publishes an INSPIRE ATOM download service for the Addresses theme; the dataset is described as a 2D vector database of addresses by municipality, structured according to INSPIRE Annex I Addresses and built from INE's Ficheiro Nacional de Alojamentos (FNA, national dwellings file) — [INE INSPIRE ATOM download service](https://inspire.ine.pt/AD/atom/downloadservice.html)
- The service has eight dataset feeds: Norte, Centro, Área Metropolitana de Lisboa, Alentejo, Algarve, Madeira, Açores (central and eastern groups) and Açores (western group) — [INE INSPIRE ATOM download service](https://inspire.ine.pt/AD/atom/downloadservice.html)
- Own count from the eight feeds (2026-11-11): 308 distinct municipality codes (87 Norte, 101 Centro, 19 AML, 59 Alentejo, 16 Algarve, 11 Madeira, 16 + 3 Açores); each municipality is offered as a zipped GML in four CRS (mainland: EPSG:3763, 4258, 4326, 3035; islands use EPSG:5014/5015/5016 instead of 3763); total size of one CRS set is 471.7 MB zipped — [AML feed example](https://inspire.ine.pt/AD/atom/CDG_AD_BNM_pc_AML_Atom.xml)
- Sum of the `numberMatched` attribute over all 308 municipal GML files is 6,475,977 feature members (this counts address features together with their component features such as postal descriptors and street names) — own count by range requests against files such as [Addresses_1106_EPSG4326.zip](https://inspire.ine.pt/AD/atom/gml/Addresses_1106_EPSG4326.zip)
- Sample (Lisbon municipality, code 1106; 21.8 MB ZIP, 942.7 MB GML): 336,033 feature members of which 324,640 have an address locator; each address has a point (`specification` = building, `method` = byAdministrator), locator designators typed as buildingIdentifier (door number), floorIdentifier and unitIdentifier (for example "ESQ", "DTO"), level `unitLevel`, and links to a PostalDescriptor (postcodes such as 1000-001), a thoroughfare name and administrative units; identifier namespace `http://id.igeo.pt/so/AD/Address` — [Addresses_1106_EPSG4326.zip, verified download](https://inspire.ine.pt/AD/atom/gml/Addresses_1106_EPSG4326.zip)
- Vintage: the Lisbon GML carries `versionId` 2017, `validFrom` 2018-01-01 and a generation timestamp of 2018-01-22; the server reports Last-Modified 17 April 2018 for the ZIP; feed entries are dated 2017-05-17 and the feed itself 2019-11-11 — [Addresses_1106_EPSG4326.zip](https://inspire.ine.pt/AD/atom/gml/Addresses_1106_EPSG4326.zip); [AML feed](https://inspire.ine.pt/AD/atom/CDG_AD_BNM_pc_AML_Atom.xml)
- Licence: the national open data portal entry gives "Acesso público sem restrições" and "Licença de utilização - CC-BY-4.0"; the feed's rights element says "Sem restrições" — [dados.gov.pt, Base Nacional de Moradas (API record)](https://dados.gov.pt/api/1/datasets/base-nacional-de-moradas/); [AML feed](https://inspire.ine.pt/AD/atom/CDG_AD_BNM_pc_AML_Atom.xml)
- No registration or key: the files downloaded directly over HTTPS — [Addresses_0110_EPSG4258.zip](https://inspire.ine.pt/AD/atom/gml/Addresses_0110_EPSG4258.zip)
- The portal entry says the description covers "moradas de Portugal Continental por município", lists frequency "continuous", last modification 2025-01-08, and is harvested from the SNIG catalogue of the Direção-Geral do Território — [dados.gov.pt, Base Nacional de Moradas](https://dados.gov.pt/datasets/base-nacional-de-moradas)

- Porto de Mós "Toponímia da rede viária e numeração de polícia": WFS, licence unknown — [dados.gov.pt](https://dados.gov.pt/datasets/toponimia-da-rede-viaria-e-numeracao-de-policia-porto-de-mos)

- A portal search for "códigos postais" returned zero datasets; a search for "moradas" returned three, of which only the BNM is an address dataset — [dados.gov.pt API search](https://dados.gov.pt/api/1/datasets/?q=moradas&page_size=12)

### Inferences
- The BNM is realistically the best free national source: it is the only countrywide dataset with door numbers, coordinates and postcodes under an open licence. Because the published files have not changed since 2018, buildings and streets created after about 2017 are missing, and the "continuous" frequency in the metadata describes the register, not the download.
- BNM records are dwelling-level (one record per floor/unit) positioned at the building, so the number of distinct door-number addresses is far lower than the 6.5 million feature members; deduplication on building identifier plus street is needed for a house-number dataset.
- BNM contains residential addresses only (it derives from the dwellings file), so commercial and public buildings are under-represented.
- The HVD regulation changed the labelling (HVD tag, INE HVD page) but not the data itself.
- The CTT file can supplement postcodes and street names but cannot be treated as open data: terms were not readable without logging in, and the only "licence" in circulation is a third party's presumption.

### Gaps
- CTT's actual terms of use for the downloadable postcode file, its update frequency and whether commercial reuse is allowed: not verified (login wall).
- Whether INE plans a refreshed BNM release based on the 2021 census: no announcement found.
- No door-number dataset was found for Lisbon or Porto municipalities in the searches run; their municipal portals were not searched exhaustively.
- Direção-Geral do Território: no address dataset of its own was found; it operates the SNIG catalogue from which the BNM record is harvested.
- No free official geocoding API for Portugal was found.

## Italy: which free address data sources exist, and on what terms?

### Takeaway
Italy's national register ANNCSU (Archivio Nazionale dei Numeri Civici delle Strade Urbane, run by ISTAT and the Agenzia delle Entrate) has been open since December 2024/February 2025: monthly national and regional CSV files under CC BY 4.0, no registration, with 27.4 million civic numbers in the 2 November 2026 file, 75.6% of them carrying coordinates. It has no postcodes (CAP remain a paid Poste Italiane product), and coordinate coverage is uneven between municipalities, so regional and municipal datasets remain useful complements.

### Cited Findings

**National register: ANNCSU (ISTAT + Agenzia delle Entrate)**
- ANNCSU is the national reference for municipal street directories; the site lists an "Open data" section, a street/civic-number search, an archive update status page and a georeferencing page; contacts are at ISTAT and the Agenzia delle Entrate — [anncsu.gov.it](https://www.anncsu.gov.it/)
- The open data page explains that Implementing Regulation (EU) 2023/138 placed addresses among geospatial high-value datasets that must be provided as open data, and that ISTAT and the Agenzia, with ANCI, adopted a new version of the ANNCSU technical specifications by inter-departmental provision of 12 December 2024 after a positive opinion of the data protection authority — [ANNCSU open data](https://www.anncsu.gov.it/it/consultazione-dellarchivio/open-data/)
- Datasets: street directories (stradari) and address lists (indirizzari) for the whole country or single regions, as CSV text files compressed as ZIP, "aggiornati mensilmente", with the creation date in the file name; data include "SNC" accesses (without a standard civic number) entered by municipalities in 2014–2016 — [ANNCSU open data](https://www.anncsu.gov.it/it/consultazione-dellarchivio/open-data/)
- Download links follow the pattern `https://anncsu.open.agenziaentrate.gov.it/age-inspire/opendata/anncsu/getds.php?INDIR_ITA` (national addresses), `?STRAD_ITA` (national streets) and regional codes such as `INDIR_LOMB`, `INDIR_VALL`, `INDIR_TREN` (20 regional pairs) — [ANNCSU bulk download page](https://www.anncsu.gov.it/it/consultazione-dellarchivio/open-data/Accedi-ai-servizi-di-dowload-massivo-in-Open-data/)
- Verified 2026-11-11: plain GET requests work without registration, key or referer (HEAD requests are answered with HTTP 403). National address file: `indirizzarioItalia.zip`, 336,334,007 bytes, containing `INDIR_ITA_20261102.csv` of 2,206,534,790 bytes; national street file `stradarioItalia.zip`, 13,920,082 bytes; Lombardia address file 36,906,989 bytes — [getds.php?INDIR_ITA](https://anncsu.open.agenziaentrate.gov.it/age-inspire/opendata/anncsu/getds.php?INDIR_ITA); [getds.php?STRAD_ITA](https://anncsu.open.agenziaentrate.gov.it/age-inspire/opendata/anncsu/getds.php?STRAD_ITA)
- Own count in `INDIR_ITA_20261102.csv`: 27,413,752 address rows; 20,728,959 (75.62%) have coordinates; 818,455 rows are flagged SNC; 7,891 distinct municipality codes appear, 5,502 of them with at least one coordinate and 4,454 with coordinates on every row — [getds.php?INDIR_ITA](https://anncsu.open.agenziaentrate.gov.it/age-inspire/opendata/anncsu/getds.php?INDIR_ITA)
- Own count of coordinate method codes: 10,892,898 rows method 4, 7,118,388 method 3, 1,721,955 method 1, 705,060 method 5, 290,658 method 2 — [getds.php?INDIR_ITA](https://anncsu.open.agenziaentrate.gov.it/age-inspire/opendata/anncsu/getds.php?INDIR_ITA)
- Coverage is uneven: in the Valle d'Aosta file (94,256 rows, 74 municipalities) only 20.4% of rows and 20 municipalities have coordinates — [getds.php?INDIR_VALL](https://anncsu.open.agenziaentrate.gov.it/age-inspire/opendata/anncsu/getds.php?INDIR_VALL)
- Fields of the address file (semicolon-separated, UTF-8, decimal comma): `CODICE_COMUNE` (Belfiore code), `CODICE_ISTAT`, `PROGRESSIVO_NAZIONALE` (national street id), `CODICE_COMUNALE`, `ODONIMO`, `LOCALITA'`, `DIZIONE_LINGUA1`, `DIZIONE_LINGUA2` (bilingual names), `PROGRESSIVO_ACCESSO` (national access id), `CODICE_COMUNALE_ACCESSO`, `CIVICO`, `ESPONENTE`, `SPECIFICITA` (for example ROSSO/NERO), `METRICO`, `PROGRESSIVO_SNC`, `COORD_X_COMUNE`, `COORD_Y_COMUNE`, `QUOTA`, `METODO`. There is no postcode (CAP) field — [metadata_indirizzario.json](https://www.anncsu.gov.it/.allegati/metadata_indirizzario.json)
- Coordinates are longitude/latitude in decimal degrees (7 decimals) in the national geodetic reference system ETRF2000 epoch 2008.0 (ETRS89 realisation); `METODO` codes: 1 field survey with accuracy under 5 m, 2 field survey ≥ 5 m, 3 indirect derivation from a territorial database under 5 m, 4 indirect derivation ≥ 5 m, 5 derived through the functions of the municipalities' portal — [metadata_indirizzario.json](https://www.anncsu.gov.it/.allegati/metadata_indirizzario.json)
- Street file fields include `TOTALE_ACCESSI` (number of civic numbers per street) — [metadata_stradario.json](https://www.anncsu.gov.it/.allegati/metadata_stradario.json)
- Coordinates exist only where the municipality entered them; each access has a numeric code that never changes even if the civic number or street name changes; coordinates are not historised; the site reported 4,304 municipalities with all civic numbers georeferenced at 31/03/2026 — [ANNCSU georeferencing page](https://www.anncsu.gov.it/it/consultazione-dellarchivio/georeferenziazione-numeri-civici/); [anncsu.gov.it](https://www.anncsu.gov.it/)
- Licence and HVD status: the catalogue entry "Stradari ed indirizzari regionali e nazionali da ANNCSU" (publisher Agenzia delle Entrate, 42 distributions) is licensed CC-BY-4.0, flagged as a high-value dataset (category Geospatial), cites Implementing Regulation 2023/138 as applicable legislation, has monthly periodicity and a modification date of 2024-12-10 — [data.europa.eu record (API)](https://data.europa.eu/api/hub/search/datasets/age-strad_ind_italia~~1)
- Press coverage of 26/02/2025 announced the Agenzia delle Entrate open data services as active: street and address lists updated monthly, point services updated daily, licence CC BY 4.0 with citation of the source; the same release opened cadastral parcels by WFS and bulk GML (Trento and Bolzano excluded from the cadastral bulk download) — [LavoriPubblici, 26/02/2025](https://www.lavoripubblici.it/news/stampa/35094)
- Query API: `querydata.php` returns JSON for street names (`resource=odonimi&codicecomune=H501&denominazione=...`) and civic numbers (`resource=accessi&progressivoodonimo=...&accesso=...`); it answered without a key on 2026-11-11 — [ANNCSU querydata service](https://anncsu.open.agenziaentrate.gov.it/age-inspire/opendata/anncsu/querydata.php)
- Earlier state for contrast (secondary, search summaries not opened in full): a 2022 OSM mailing-list post expected bulk download without coordinates, and a 2025 presentation reported 4.9% of records with coordinates — [talk-it, May 2022](https://lists.openstreetmap.org/pipermail/talk-it/2022-May/073872.html); [ANNCSU presentation, July 2025](https://www.sportellotelematicopolifunzionale.it/sites/default/files/2025-07/Presentazione%20ANCSSU%20.pdf)
- OpenAddresses now uses ANNCSU as its Italy countrywide source (CC-BY 4.0, attribution "Istat e dall'Agenzia delle Entrate"; cached file `INDIR_ITA_20260703_GEO.csv`) — [OpenAddresses sources/it/countrywide.json](https://github.com/openaddresses/openaddresses/blob/master/sources/it/countrywide.json)

**Postcodes: Poste Italiane**
- Poste Italiane FAQ (June 2019): complete CAP files cannot be downloaded for free because "la banca dati del CAP è di proprietà di Poste Italiane che ne detiene i diritti intellettuali ed industriali"; only lookup tools (Cerca CAP, contact centre) are free; CAP Professional (MS Access) and CAP Zone (shapefile) are commercial products — [Poste Italiane, FAQ banche dati CAP](https://business.poste.it/business/files/1473808238165/banchedati-faq-cap.pdf)

### Inferences
- ANNCSU is now the primary free source for Italy and makes most older regional extracts secondary. Regional and municipal files still matter for (a) the roughly one quarter of civic numbers without coordinates, (b) better positional accuracy (over half of ANNCSU coordinates are method 4, estimated accuracy of 5 m or worse), and (c) postcodes, which a few municipal datasets such as Bologna include.
- The count of 7,891 municipality codes suggests almost every Italian municipality is present in the file, but presence does not prove that each municipality's civic numbers are complete; this was not tested.
- The jump from a reported 4.9% georeferenced (2025, secondary) to 75.6% (November 2026, own count) implies a large loading campaign during 2025–2026; method codes 3–5 dominate, so most new coordinates were derived from existing databases, not surveyed.
- A full Italian address with postcode cannot be built from open official data alone: CAP must come from Poste Italiane (paid) or non-official sources.
- Parsing notes: coordinates use a decimal comma, the delimiter is a semicolon, and X is longitude.

### Gaps
- Official list of municipalities whose ANNCSU data are incomplete or unvalidated: the status page loads its figures by script and could not be read.
- No official statement of rate limits or terms for `querydata.php` was found.
- No region-wide open address dataset was found for Veneto or the Province of Trento in the searches run (only municipal files such as Verona and Venezia).
- Lombardia, Umbria and Piemonte regional downloads could not be confirmed live on 2026-11-11.
- ISTAT publishes no separate address download that I could find; its role is co-ownership of ANNCSU.

## Malta: which free address data sources exist, and on what terms?

### Takeaway
Malta has no open address-point dataset. A statutory Address Register was created in September 2025 under a new Office of the Address Registrar, but what it publishes openly so far is reference lists only (6 regions, 85 localities, 68 local councils, 8,502 streets) through a CC BY 4.0 JSON API with no door numbers, coordinates or postcodes. Postcodes are held by MaltaPost, which offers a single-address lookup and, by regulatory decision, a full database on request at no cost.

### Cited Findings

**Address Register (Office of the Address Registrar)**
- The Office of the Address Registrar was set up under Legal Notice 205 of 2025 (Address Register and related Location (Geospatial) Registers Regulations, 2025), published 23 September 2025; it took over the Address Management Unit that had operated in the Electoral Office since 2016 (door numbering, street naming); the Address Register is intended as the authoritative registry of all streets and addresses in the Maltese archipelago, including spatial data — [address.gov.mt](https://address.gov.mt/)
- Public services on the site: "Research Spot" (search official door-numbering and street-naming publications from 1997), "Locate a Street", and registers of local councils, localities and regions; the page describes no address-level download — [address.gov.mt](https://address.gov.mt/)
- The API namespace exposes exactly these routes: `/gov/v1/regions`, `/gov/v1/localities`, `/gov/v1/local-councils`, `/gov/v1/streets`, `/gov/v1/openapi.json`; requests for `/addresses` or `/doors` return "rest_no_route" (verified 2026-11-11) — [address.gov.mt API index](https://address.gov.mt/wp-json/gov/v1)
- Verified content: streets endpoint returns 8,502 records (1.38 MB JSON) with `street_name`, `street_code`, `locality`, `region`, `local_council`; localities 85 records; regions 6; local councils 68; no coordinates, door numbers or postcodes in any of them; no key needed — [streets API](https://address.gov.mt/wp-json/gov/v1/streets); [localities API](https://address.gov.mt/wp-json/gov/v1/localities)
- Catalogue entries: "Streets Dataset", "Localities Dataset", "Regions Dataset" (issued 2026-03-27, modified 2026-09-14) and "Local Councils of Malta" (issued 2026-06-23) by the Office of the Address Registrar, each with one API distribution licensed CC BY 4.0; none is flagged as a high-value dataset — [data.europa.eu search, Malta "Address Registrar"](https://data.europa.eu/api/hub/search/search?q=Address%20Registrar&filter=dataset&facets=%7B%22country%22%3A%5B%22mt%22%5D%7D&limit=10)
- The Streets Dataset is defined as records of all publicly or privately owned streets that serve as thoroughfares and are assigned a name by the Registrar — [data.europa.eu record, Streets Dataset](https://data.europa.eu/api/hub/search/datasets/0d102ee6-a173-46b4-8b6d-bacf9bba93fb)

**Postcodes: MaltaPost**
- MaltaPost runs a web "Postcode Finder" (page title "MaltaPost - Postcode Finder", HTTP 200 on 2026-11-11); the older host `postcodes.maltapost.com` no longer resolves — [MaltaPost Postcode Finder](https://www.maltapost.com/PostCode/)
- The Malta Communications Authority decision of 14 May 2018 keeps the condition that "Third parties (in particular bulk mail senders) requiring a full postcode database will be provided with one at no cost", unless another entity makes an equivalent database available; MaltaPost stated it was already giving entities access to the whole postcode database and described itself as custodian and originator of Malta's postcode system — [MCA, Postcodes decision notice, 14 May 2018](https://www.mca.org.mt/sites/default/files/Postcodes%20Decision_1.pdf)
- A search of the EU data portal for Maltese datasets matching "postcode" returned zero results — [data.europa.eu search, Malta "postcode"](https://data.europa.eu/api/hub/search/search?q=postcode&filter=dataset&facets=%7B%22country%22%3A%5B%22mt%22%5D%7D&limit=10)

**Other bodies checked**
- Planning Authority: "Large Scale Topography Buildings" is flagged as a high-value dataset and served by WFS/WMS and OGC API under CC BY 4.0; it is a buildings dataset, not addresses — [Planning Authority buildings WFS](https://haleconnect.com/ows/services/org.1261.af1f626c-3200-4fb6-8ae0-a3426b6b4a6e_wfs?SERVICE=WFS&Request=GetCapabilities); [data.europa.eu search, Malta "buildings"](https://data.europa.eu/api/hub/search/search?q=buildings&filter=dataset&facets=%7B%22country%22%3A%5B%22mt%22%5D%7D&limit=6)

- Identità lists "Person Basic Details" and "Person Household Details" (latest known address of persons) in the catalogue with no distributions, that is, not open — [data.europa.eu search, Malta "address"](https://data.europa.eu/api/hub/search/search?q=address&filter=dataset&facets=%7B%22country%22%3A%5B%22mt%22%5D%7D&limit=10)
- The national portals `portal.data.gov.mt` and `msdi.data.gov.mt` returned HTTP 403 with a Cloudflare challenge to non-browser clients on 2026-11-11, so their own catalogue pages could not be read directly — [portal.data.gov.mt, Streets Dataset](https://portal.data.gov.mt/dataset/streets-dataset)

### Inferences
- The best free official material for Malta is the street gazetteer API (useful for validating street names and their locality/council), which is not an address dataset. For house-number-level data with coordinates the realistic free option is OpenStreetMap, covered by another researcher.
- The 2025 legal basis and the stated aim that the register include spatial data make a future open address-point release plausible, but no date or commitment was found.
- Malta has not published addresses as a high-value dataset: the only address-related open datasets are not HVD-flagged, and the HVD-flagged geospatial item found is buildings.
- The MaltaPost full database "at no cost" is a request-based entitlement aimed at bulk mailers, not open data; reuse terms are unknown.

### Gaps
- Licence, format, content and procedure for obtaining MaltaPost's full postcode database: not published anywhere I could find.
- Whether the Address Register holds door-level points with coordinates that could be requested: not stated on address.gov.mt.
- The EU INSPIRE Geoportal could not be consulted (expired TLS certificate on 2026-11-11), so the absence of a Maltese INSPIRE Addresses dataset rests on the data.europa.eu search only.
- The text of Legal Notice 205 of 2025 (access and reuse provisions) was not read.
- Lands Authority: no address dataset found; its site was not examined in depth.

## How do the four countries compare on the key questions?

### Takeaway
Spain and Italy offer current, countrywide, openly licensed address points; Portugal offers an open but 2018-vintage one; Malta offers none. Postcodes come with the open data only in Spain and Portugal.

### Cited Findings
- Spain: CartoCiudad, CC BY 4.0, 15,662,297 address features in the OGC API, four-monthly, postcodes included, HVD category Addresses — [api-features.idee.es](https://api-features.idee.es/collections/address/items?f=json&limit=1); [datos.gob.es record](https://datos.gob.es/es/catalogo/e0dat0002-direcciones-postales-de-cartociudad)
- Portugal: Base Nacional de Moradas, CC-BY-4.0, 308 municipal GML files with 6,475,977 feature members, files last modified April 2018, postcodes included, tagged HVD — [INE ATOM service](https://inspire.ine.pt/AD/atom/downloadservice.html); [dados.gov.pt](https://dados.gov.pt/datasets/base-nacional-de-moradas)
- Italy: ANNCSU, CC-BY-4.0, 27,413,752 rows in the 2 November 2026 national file, monthly, 75.6% with coordinates, no postcodes, flagged HVD — [ANNCSU bulk download](https://www.anncsu.gov.it/it/consultazione-dellarchivio/open-data/Accedi-ai-servizi-di-dowload-massivo-in-Open-data/); [data.europa.eu record](https://data.europa.eu/api/hub/search/datasets/age-strad_ind_italia~~1)
- Malta: street list only (8,502 streets), CC BY 4.0, not HVD — [address.gov.mt streets API](https://address.gov.mt/wp-json/gov/v1/streets)
- Registration: none needed for the Italian, Portuguese and Maltese downloads or the Spanish APIs and Catastro feed; the Spanish CNIG file downloads require passing reCAPTCHA; the Portuguese CTT postcode file requires an account — [CNIG CartoCiudad page](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad); [CTT download page](https://www.ctt.pt/feapl_2/app/restricted/postalCodeSearch/postalCodeDownloadFiles.jspx)

### Inferences
- Regulation (EU) 2023/138 had a visible effect in Italy (ANNCSU opened in direct response, per its own open data page) and Spain (HVD-tagged services, GeoPackage and OGC API delivery), a labelling-only effect in Portugal, and no visible effect on addresses in Malta.
- Free official geocoding APIs exist for Spain (CartoCiudad, plus ICGC for Catalonia) and in a limited lookup form for Italy (ANNCSU querydata); none was found for Portugal or Malta.

### Gaps
- Counts are not like-for-like: Spain's figure is address points, Portugal's is GML feature members at dwelling-unit level, Italy's is civic-number rows including those without coordinates.
