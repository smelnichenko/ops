## Research notes (first layer, as the researcher wrote them)

**Source section: Spain: which free address data sources exist, and on what terms?**

### Takeaway
Spain has open, free, house-number-level address data with coordinates and postcodes for the whole country: CartoCiudad (IGN/CNIG, CC BY 4.0, ~15.7 million address points, rebuilt every four months) is the national aggregate and is the dataset declared as the "Addresses" High-Value Dataset; the Catastro INSPIRE Addresses ATOM feed is the main underlying source (free, no registration, updated twice a year, but excludes the Basque Country and Navarra, which publish their own data). The one practical obstacle is that the CNIG download centre gates file downloads behind reCAPTCHA, so unattended bulk download is easier through the OGC API Features service or the Catastro ATOM feed.

### Cited Findings

**National aggregate: CartoCiudad (IGN / CNIG, Sistema Cartográfico Nacional)**
- CartoCiudad ("Direcciones postales de CartoCiudad") is published by the Centro Nacional de Información Geográfica (CNIG) for the Instituto Geográfico Nacional; the download product is a spatial dataset per province in GeoPackage format with the layers `portalpk_publi` (address points: portales and kilometre points) and `manzana` (urban blocks) — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad)
- Download unit is the province (52 files; examples: A Coruña 51.24 MB, Barcelona 141.81 MB, Araba/Álava 2.84 MB, Ceuta 1.04 MB); CRS is ETRS89 geographic longitude/latitude for the peninsula, Balearics, Ceuta and Melilla, and REGCAN95 for the Canary Islands; road geometries are not included (they are in the separate "Redes de Transporte" product) — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad)
- Attributes of `portalpk_publi` (specification v15, PDF dated 2025-12-18): `id`, `id_porpk`, `tipo` (Portal or PK), `tipo_vial`, `nombre_via`, `numero`, `extension`, `id_pob`, `poblacion`, `cod_postal` (mandatory), `ine_mun`, `municipio`, `provincia`, `comunidad_autonoma`, `fuente_datos`, `fecha_modificacion`; geometry is a point — [CartoCiudad documentation ZIP (contains CartoCiudad_Especificaciones_v15.pdf), verified download 2026-11-11](https://centrodedescargas.cnig.es/CentroDescargas/documentos/Cartociudad_documentacion.zip)
- Update frequency for postal addresses is "cuatrimestral" (every four months); in each cycle the dataset is regenerated completely and replaces the previous version — [CartoCiudad documentation ZIP, specification v15 section 8](https://centrodedescargas.cnig.es/CentroDescargas/documentos/Cartociudad_documentacion.zip); same frequency stated in [CNIG "Fuentes oficiales – Direcciones postales", May 2026](https://www.idee.es/resources/documentos/Cartociudad/Fuentes_direcciones.pdf)
- Release log: latest release 10-11-2026 (portals and kilometre points updated from national, regional and local sources); earlier releases 11-05-2026, 02-03-2026, 20-11-2025 (new attribute giving the data source of each address), 13-06-2025 (new attributes for update date and municipality/province/region), 10-06-2024 (data now provided in GeoPackage format; addresses linked to latest Correos postcodes), 15-12-2023 — [CNIG novedades, CartoCiudad series](https://centrodedescargas.cnig.es/CentroDescargas/novedades?codSerie=02122)
- Licence: access unrestricted, use "Datos sujetos a licencia CC BY 4.0" per the specification; the download page refers to Orden FOM/2807/2015 and an IGN licence described as compatible with CC BY 4.0; attribution is required — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad); [Orden FOM/2807/2015](https://www.boe.es/boe/dias/2015/12/26/pdfs/BOE-A-2015-14129.pdf); [IGN licence conditions](http://www.ign.es/resources/licencia/Condiciones_licenciaUso_IGN.pdf)
- Commercial reuse: CNIG states that all users can use, reuse and redistribute the information "sin discriminación alguna ni restricciones de uso comercial" — [CNIG paper, JIIDE 2024](https://www.idee.es/resources/documentos/Cartociudad/JIIDE/2024_publicacion_datos_geoespaciales_alto_valor_cartociudad.pdf)
- Suggested attribution string used by reusers: "CC BY 4.0 www.scne.es/productos.html#CartoCiudad" — [datos.gob.es, Callejero Digital de Andalucía Unificado record](https://datos.gob.es/en/catalogo/e0dat0002-callejero-digital-de-andalucia-unificado); OpenAddresses records the licence as CC BY 4.0 with attribution name "scne.es" — [OpenAddresses sources/es/countrywide.json](https://github.com/openaddresses/openaddresses/blob/master/sources/es/countrywide.json)
- Registration and automation (verified in the page source 2026-11-11): the download page shows an optional "Iniciar sesión" link, and each direct download first calls `preAutorizarDescarga` with a Google reCAPTCHA v3 token and runs a check for automated browsers (`navigator.webdriver`) before the file is served. I did not attempt to pass this gate — [CNIG Centro de Descargas, CartoCiudad](https://centrodedescargas.cnig.es/CentroDescargas/cartociudad)
- Sources integrated by CartoCiudad (May 2026 list): IGN transport network (IGR-RT), Dirección General del Catastro, Gobierno Vasco, CDAU (Andalucía), IDE Catalunya (INSPIRE addresses), Gobierno de La Rioja, Gobierno de Navarra, Institut Cartogràfic Valencià, Comunidad de Madrid, Govern Illes Balears, and the municipalities of Cáceres, Albacete, Santander, València, Caravia, Gijón, Santa Cruz de Tenerife, Soto del Barco, Sariego, Gozón, Oviedo, Avilés, Pravia and Navia — [CNIG "Fuentes oficiales – Direcciones postales", May 2026](https://www.idee.es/resources/documentos/Cartociudad/Fuentes_direcciones.pdf)
- Position of Catastro-sourced points: "Cuando es posible, el portal se sitúa en la entrada del edificio y en otros casos el centroide de la parcela catastral" — [CNIG "Fuentes oficiales – Direcciones postales", May 2026](https://www.idee.es/resources/documentos/Cartociudad/Fuentes_direcciones.pdf)

**CartoCiudad APIs and services (all free, no key; verified live 2026-11-11)**
- OGC API Features: collection `address` ("AD Dirección") at api-features.idee.es returned `numberMatched: 15662297`; a request with `limit=10000` returned 10,000 features (10.1 MB of GeoJSON in 5.4 s) with a `next` link for paging. Properties per feature: `inspireId_namespace` (ES.SCNE.CARTOCIUDAD), `component_ThoroughfareName`, `locator_designator_addressNumber`, `locator_designator_addressNumberExtension`, `component_PostalDescriptor` (postcode), `component_AdminUnitName_2/3/4`, `component_AddressAreaName`, `dataProvider`, `beginLifespanVersion`; geometry is a WGS84/ETRS89 lon-lat point — [api-features.idee.es address items](https://api-features.idee.es/collections/address/items?f=json&limit=1); [collection page](https://api-features.idee.es/collections/address)

- INSPIRE WFS 2.0 for addresses responds at `https://www.cartociudad.es/wfs-inspire/direcciones` (title "Direcciones") — [WFS GetCapabilities](https://www.cartociudad.es/wfs-inspire/direcciones?service=WFS&request=GetCapabilities)

### Inferences
- Spain has no single statutory national address register; CartoCiudad is an aggregate rebuilt from cadastral, statistical, regional and municipal sources, so it is the best single free source but inherits the quality and vintage of each contributor (the `fuente_datos` and `fecha_modificacion` attributes make this traceable).
- For unattended bulk acquisition the realistic routes are (a) paging the OGC API Features `address` collection (about 1,570 requests at 10,000 features each) or (b) the Catastro ATOM feed (thousands of small per-municipality ZIPs, plus Navarra and Basque sources separately); the CNIG GeoPackages need a browser because of reCAPTCHA.
- The gap between "19 million" addresses in the geocoder (June 2024) and 15.66 million in the API collection (November 2026) probably reflects different content scopes or de-duplication, not a loss of coverage; this is not confirmed by any source.
- The Catastro licence position is ambiguous: current metadata says CC BY 4.0 while the linked 2016 licence PDF restricts redistribution of untransformed data. Reusers who redistribute raw Catastro files should rely on the CartoCiudad CC BY 4.0 release or seek confirmation.
- The Navarra CSV coordinates look like ETRS89 / UTM zone 30N metres despite the `lon`/`lat` column names (inferred from value ranges only).

### Gaps
- Exact record count and total size of the 52 CartoCiudad GeoPackages: not measured because downloads are behind reCAPTCHA.
- Rate limits or fair-use terms for the CartoCiudad geocoder and API Features: none found on the pages opened.
- A direct bulk download URL for the Basque Country street directory (geoEuskadi FTP) was not found; licence appears as CC BY 3.0 in one catalogue and CC BY 4.0 (NORA) in a secondary source.
- Whether Catastro has formally replaced its 2016 licence text with CC BY 4.0: unresolved.
- Correos' own postcode products and prices were not checked; no open Correos download was found.
