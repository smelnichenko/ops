## Research notes (first layer, as the researcher wrote them)

**Source section: Portugal: which free address data sources exist, and on what terms?**

### Takeaway
Portugal does have an open national address-point dataset: INE's "Base Nacional de Moradas" (National Address Base), an INSPIRE Addresses dataset for all 308 municipalities with coordinates, door numbers, unit designators and postcodes, under CC BY 4.0, downloadable without registration. Its weakness is age: the files on the server date from January–April 2018 (version 2017) even though the metadata calls the update frequency "continuous". The CTT postcode file needs a free account and has no coordinates; current door-number data exists only for a few municipalities.

### Cited Findings

**National dataset: Base Nacional de Moradas (BNM), Instituto Nacional de Estatística (INE)**
- INE publishes an INSPIRE ATOM download service for the Addresses theme; the dataset is described as a 2D vector database of addresses by municipality, structured according to INSPIRE Annex I Addresses and built from INE's Ficheiro Nacional de Alojamentos (FNA, national dwellings file) — [INE INSPIRE ATOM download service](https://inspire.ine.pt/AD/atom/downloadservice.html)
- The service has eight dataset feeds: Norte, Centro, Área Metropolitana de Lisboa, Alentejo, Algarve, Madeira, Açores (central and eastern groups) and Açores (western group) — [INE INSPIRE ATOM download service](https://inspire.ine.pt/AD/atom/downloadservice.html)
- Own count from the eight feeds (2026-11-11): 308 distinct municipality codes (87 Norte, 101 Centro, 19 AML, 59 Alentejo, 16 Algarve, 11 Madeira, 16 + 3 Açores); each municipality is offered as a zipped GML in four CRS (mainland: EPSG:3763, 4258, 4326, 3035; islands use EPSG:5014/5015/5016 instead of 3763); total size of one CRS set is 471.7 MB zipped — [AML feed example](https://inspire.ine.pt/AD/atom/CDG_AD_BNM_pc_AML_Atom.xml)
- Sum of the `numberMatched` attribute over all 308 municipal GML files is 6,475,977 feature members (this counts address features together with their component features such as postal descriptors and street names) — own count by range requests against files such as [Addresses_1106_EPSG4326.zip](https://inspire.ine.pt/AD/atom/gml/Addresses_1106_EPSG4326.zip)
- Sample (Lisbon municipality, code 1106; 21.8 MB ZIP, 942.7 MB GML): 336,033 feature members of which 324,640 have an address locator; each address has a point (`specification` = building, `method` = byAdministrator), locator designators typed as buildingIdentifier (door number), floorIdentifier and unitIdentifier (for example "ESQ", "DTO"), level `unitLevel`, and links to a PostalDescriptor (postcodes such as 1000-001), a thoroughfare name and administrative units; identifier namespace `http://id.igeo.pt/so/AD/Address` — [Addresses_1106_EPSG4326.zip, verified download](https://inspire.ine.pt/AD/atom/gml/Addresses_1106_EPSG4326.zip)
- Vintage: the Lisbon GML carries `versionId` 2017, `validFrom` 2018-01-01 and a generation timestamp of 2018-01-22; the server reports Last-Modified 17 April 2018 for the ZIP; feed entries are dated 2017-05-17 and the feed itself 2019-11-11 — [Addresses_1106_EPSG4326.zip](https://inspire.ine.pt/AD/atom/gml/Addresses_1106_EPSG4326.zip); [AML feed](https://inspire.ine.pt/AD/atom/CDG_AD_BNM_pc_AML_Atom.xml)
- Licence: the national open data portal entry gives "Acesso público sem restrições" and "Licença de utilização - CC-BY-4.0"; the feed's rights element says "Sem restrições" — [dados.gov.pt, Base Nacional de Moradas (API record)](https://dados.gov.pt/api/1/datasets/base-nacional-de-moradas/); [AML feed](https://inspire.ine.pt/AD/atom/CDG_AD_BNM_pc_AML_Atom.xml)
- No registration or key: the files downloaded directly over HTTPS — [Addresses_0110_EPSG4258.zip](https://inspire.ine.pt/AD/atom/gml/Addresses_0110_EPSG4258.zip)
- The portal entry says the description covers "moradas de Portugal Continental por município", lists frequency "continuous", last modification 2025-01-08, and is harvested from the SNIG catalogue of the Direção-Geral do Território — [dados.gov.pt, Base Nacional de Moradas](https://dados.gov.pt/datasets/base-nacional-de-moradas)
- OpenAddresses uses this INE service as its Portugal countrywide source, licence CC BY 4.0, attribution "Instituto Nacional de Estatística, I.P."; its cached conversion is dated 2026-02-23 — [OpenAddresses sources/pt/countrywide.json](https://github.com/openaddresses/openaddresses/blob/master/sources/pt/countrywide.json)
- Limits reported by the OSM community (secondary, 2021): the base does not include businesses and facilities; INE authorised its import in writing — [OSM wiki, Portugal address import](https://wiki.openstreetmap.org/wiki/Portugal/Projetos/Importa%C3%A7%C3%A3o_de_endere%C3%A7os)

**High-Value Dataset status**
- The portal entry is tagged `hvd` and states the dataset "integra os Conjuntos de Dados de Elevado Valor/HVD identificados de acordo com o Regulamento de Execução n.º 2023/138" — [dados.gov.pt, Base Nacional de Moradas](https://dados.gov.pt/datasets/base-nacional-de-moradas)
- INE's own HVD geospatial page lists "National Address Base" under theme Addresses with a download link to the ATOM service, and "Geographic Base of Buildings" under theme Buildings with a metadata link only (no download link shown); page content is licensed CC BY 4.0 — [INE High-Value Data Sets, geospatial](https://www.ine.pt/scripts/hvd/en/geo.html)

**Postal operator: CTT postcode file**
- The CTT download page for postcode files redirects to a login (CAS) page, so an account is required — [CTT postal code download page](https://www.ctt.pt/feapl_2/app/restricted/postalCodeSearch/postalCodeDownloadFiles.jspx)
- A community conversion describes the CTT file as the full list of postcodes for mainland and islands with more than 300,000 entries of three kinds (CTT customers with their own postcode, localities, streets and street segments); access "requer o registo e o log-in"; the republication under PDDL is explicitly a presumption ("Presume-se que a informação aqui contida é de caráter público") — [centraldedados/codigos_postais](https://github.com/centraldedados/codigos_postais)

**Statistical office: Base Geográfica de Edifícios (BGE)**
- The BGE (building points georeferenced by census enumerators in 2011, with residential buildings added or corrected during the 2021 census) has an INSPIRE metadata record with public access (secondary, from a search summary; the INSPIRE Geoportal could not be opened on 2026-11-11 because its TLS certificate had expired) — [INSPIRE Geoportal record ad14e031](https://inspire-geoportal.ec.europa.eu/srv/api/records/ad14e031-a2c1-4673-a85b-3b57b0df3767)
- INE's HVD page shows no download link for the BGE — [INE High-Value Data Sets, geospatial](https://www.ine.pt/scripts/hvd/en/geo.html)

**Municipal sources on dados.gov.pt (search of 2026-11-11)**
- Cascais "Números de Polícia": CC BY, GeoJSON/CSV/SHP/KML, last modified 2026-11-09 — [dados.gov.pt](https://dados.gov.pt/datasets/geocascais-numerospolicia)
- Oeiras "Toponímia: Números de Polícia": CC BY, WFS, last modified 2026-10-19 — [dados.gov.pt](https://dados.gov.pt/datasets/toponimia-numeros-de-policia)
- Porto de Mós "Toponímia da rede viária e numeração de polícia": WFS, licence unknown — [dados.gov.pt](https://dados.gov.pt/datasets/toponimia-da-rede-viaria-e-numeracao-de-policia-porto-de-mos)
- Alto Tâmega e Barroso "Toponímia e numeração de polícia": CC BY, GeoPackage, 2023 — [dados.gov.pt](https://dados.gov.pt/datasets/toponimia-e-numeracao-de-policia-no-alto-tamega-e-barroso)
- Lisbon "Toponímia de Lisboa": CC0, GeoJSON (street names, not door numbers) — [dados.gov.pt](https://dados.gov.pt/datasets/toponimia-de-lisboa)
- A portal search for "códigos postais" returned zero datasets; a search for "moradas" returned three, of which only the BNM is an address dataset — [dados.gov.pt API search](https://dados.gov.pt/api/1/datasets/?q=moradas&page_size=12)

### Inferences
- The BNM is realistically the best free national source: it is the only countrywide dataset with door numbers, coordinates and postcodes under an open licence. Because the published files have not changed since 2018, buildings and streets created after about 2017 are missing, and the "continuous" frequency in the metadata describes the register, not the download.
- BNM records are dwelling-level (one record per floor/unit) positioned at the building, so the number of distinct door-number addresses is far lower than the 6.5 million feature members; deduplication on building identifier plus street is needed for a house-number dataset.
- BNM contains residential addresses only (it derives from the dwellings file), so commercial and public buildings are under-represented.
- The HVD regulation changed the labelling (HVD tag, INE HVD page) but not the data itself.
- The CTT file can supplement postcodes and street names but cannot be treated as open data: terms were not readable without logging in, and the only "licence" in circulation is a third party's presumption.

### Gaps
- CTT's actual terms of use for the downloadable postcode file, its update frequency and whether commercial reuse is allowed: not verified (login wall).
- Whether INE plans a refreshed BNM release based on the 2021 census: no announcement found.
- No door-number dataset was found for Lisbon or Porto municipalities in the searches run; their municipal portals were not searched exhaustively.
- Direção-Geral do Território: no address dataset of its own was found; it operates the SNIG catalogue from which the BNM record is harvested.
- No free official geocoding API for Portugal was found.
